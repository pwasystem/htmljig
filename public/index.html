Sobre o HTML Jig

O HTML Jig é um gerador de sites movido a Inteligência Artificial (utilizando os servidores de IA da NVIDIA). Sem necessidade de código, basta descrever sua ideia, escolher um modelo de template e o sistema gerará uma página HTML completa e pronta para uso!

Acessar a Ferramenta HTML Jig

Por que utilizar o HTML Jig?

  • Criação Rápida com IA: Gere páginas completas em poucos segundos com a tecnologia NVIDIA AI.
  • Organização Automática: Suas páginas geradas ficam salvas na pasta criações.
  • Templates Personalizáveis: Escolha entre dezenas de modelos visuais W3.CSS.

Como Utilizar o Sistema

1. Acesse o Jig

Clique no link jig.html para abrir o formulário de criação.

2. Preencha os Dados

Informe o nome do arquivo, título, descrição da empresa e escolha um template visual.

3. Gere seu Site

Clique em Criar e a IA salvará sua página na pasta criações!

Passo a passo detalhado:

  1. Acesse a ferramenta: Clique no botão Criar Site Agora ou navegue para /jig.html.
  2. Preencha os campos do formulário:
    • Nome do arquivo (File Name): Nome que a página terá (ex: minha-loja).
    • Título (Title): Título da empresa ou projeto (ex: Café Gourmet).
    • Descrição (Description): Detalhes sobre a empresa, produtos, esquema de cores e estilo desejado.
    • Template: Selecione a estrutura visual desejada (ex: Website, Cafe, Band, Portfólio).
    • Imagens (opcional): Adicione URLs de fotos para a IA incluir na página.
  3. Gerar a página: Clique no botão Criar e aguarde o processamento da IA.
  4. Visualizar o resultado: Após a criação, um link direto para a página na pasta criações (`criacoes/seu-arquivo.html`) será exibido para você abrir o site em uma nova aba!

Configuração do Servidor Nativo

O sistema roda 100% nativo em Node.js (com 0 dependências NPM) e integrado aos servidores de IA da NVIDIA.

  1. Certifique-se de ter o Node.js v18+ instalado.
  2. Verifique a chave da NVIDIA no arquivo .env.
  3. Inicie o servidor direto com node server.js e acesse http://localhost:3000!
